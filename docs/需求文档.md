# 企微客户管理系统需求文档

## 一、项目概述

**项目名称**：企微客户管理与营销系统  
**项目目标**：基于企业微信API，打造集客户管理、获客、营销于一体的后台管理系统，帮助企业高效管理客户关系，提升获客效率和营销转化。

**核心价值**：
- 统一管理企业微信客户数据
- 多渠道获客并追踪转化效果
- 精准营销提升客户活跃度和复购率
- 自动化运营降低人工成本

---

## 二、用户角色

| 角色 | 职责 | 权限级别 |
|------|------|----------|
| 超级管理员 | 系统配置、权限管理、数据查看 | 最高权限 |
| 运营人员 | 客户管理、营销活动执行、数据查看 | 业务权限 |
| 销售人员 | 客户跟进、沟通记录、任务执行 | 客户权限 |
| 普通员工 | 查看个人客户数据、接收任务 | 最低权限 |

---

## 三、功能模块详细设计

### 3.1 应用管理模块

**功能点**：
- 企业微信应用配置（AgentID、Secret管理）
- 应用权限配置（接口调用权限范围）
- 应用菜单管理（自定义菜单）
- 应用消息模板管理

**接口对接**：
- 获取access_token
- 应用管理相关API

### 3.2 客户管理模块

#### 3.2.1 客户基本信息
- **客户列表**
  - 多维度筛选：姓名/手机/备注模糊搜索、添加时间段、所属部门、跟进人、标签、客户状态
  - 列表展示：姓名、头像、所属企业、备注、添加时间、跟进人、标签、最后活跃时间、状态
  - 排序功能：按添加时间、活跃时间、互动次数升序/降序
  - 批量操作：批量打标、批量分配、批量导出、批量删除
  - 列表视图切换：列表视图/卡片视图

- **客户详情**
  - 基础信息：姓名、头像、性别、生日、手机号、邮箱、地址
  - 企业信息：所属企业名称、企业规模、行业类型、职位
  - 社交信息：微信号、邮箱、其他联系方式
  - 添加信息：添加时间、添加来源、添加渠道、添加人
  - 跟进信息：跟进人、跟进次数、最后跟进时间、下次跟进时间
  - 状态管理：客户状态（潜在/意向/成交/流失）、客户等级（S/A/B/C）
  - 操作记录：查看、编辑、删除、转移、拉黑等操作日志

- **客户编辑与删除**
  - 信息编辑：基础信息、企业信息、备注等
  - 客户转移：单个转移、批量转移（指定新跟进人）
  - 客户删除：软删除（可恢复）、永久删除（需二次确认）
  - 权限控制：仅跟进人或管理员可编辑/删除

- **批量导入导出**
  - 导入功能：Excel模板下载、批量导入、数据校验、导入结果报告
  - 导出功能：全量导出、筛选导出、自定义字段导出、定时导出
  - 数据脱敏：导出时敏感信息脱敏处理

#### 3.2.2 跟进记录
- **跟进记录新增**
  - 记录类型：电话、微信、拜访、邮件、会议、其他
  - 内容类型：文本（支持富文本）、图片（最多9张）、附件（文档、视频等）
  - 跟进结果：成功、失败、待定、已预约
  - 下次跟进：设置下次跟进时间、跟进内容备注
  - 提醒设置：短信提醒、企微消息提醒、邮件提醒、站内信提醒
  - 费用记录：跟进产生费用（交通费、礼品费等）

- **跟进记录历史**
  - 时间线展示：按时间倒序展示所有跟进记录
  - 筛选过滤：按类型、结果、时间范围筛选
  - 详情查看：查看完整跟进内容、附件下载
  - 聊天记录：同步企微聊天记录（需授权）
  - 文件管理：附件上传、下载、预览

- **跟进提醒**
  - 提醒设置：提前15分钟/30分钟/1小时/1天提醒
  - 提醒方式：企微消息、短信、邮件、站内信
  - 提醒列表：查看所有待跟进客户、支持标记完成/延迟
  - 逾期提醒：逾期未跟进的自动升级提醒
  - 批量跟进：批量设置多个客户的下次跟进时间

- **跟进统计**
  - 个人统计：跟进次数、跟进成功率、平均跟进间隔
  - 团队统计：团队成员跟进对比、团队跟进完成率
  - 客户统计：客户跟进频次、响应时间统计
  - 趋势分析：日/周/月跟进趋势图
  - 效果分析：跟进次数与成交转化相关性分析

#### 3.2.3 标签管理
- **标签组管理**
  - 创建标签组：名称、排序、颜色、描述
  - 编辑标签组：修改名称、调整顺序、更新颜色
  - 删除标签组：仅删除空标签组（需确认）
  - 标签组权限：设置可见范围（全员/部门/个人）
  - 标签组统计：每个标签组下的标签数量、客户数量

- **标签管理**
  - 创建标签：选择标签组、标签名称、排序、图标
  - 编辑标签：修改名称、更换图标、调整顺序
  - 删除标签：删除前需确认标签使用客户数量
  - 标签合并：将多个标签合并为一个标签
  - 标签颜色：支持预设颜色、自定义颜色
  - 标签类型：系统标签（不可删除）、自定义标签

- **客户打标/取消标签**
  - 单个打标：客户详情页添加/移除标签
  - 快速打标：列表页快速添加常用标签
  - 标签规则：设置标签互斥规则（同一标签组只能选一个）
  - 打标记录：记录打标时间、操作人、标签变化
  - 智能推荐：根据客户行为智能推荐标签

- **批量打标**
  - 筛选打标：按条件筛选客户后批量打标
  - 快捷打标：预设快捷打标方案（如：所有未跟进客户打"待跟进"）
  - 批量移除：批量移除指定标签
  - 批量覆盖：用新标签覆盖旧标签
  - 操作确认：批量操作前预览受影响客户数量

- **标签统计分析**
  - 标签分布：各标签客户数量、占比饼图
  - 标签交叉：多标签交叉分析（同时拥有多个标签的客户）
  - 标签趋势：标签客户数量变化趋势
  - 标签效果：带某标签客户的成交率、活跃度分析
  - 标签价值：标签对业务贡献度评估

#### 3.2.4 客户画像
- **客户基本信息展示**
  - 个人资料：姓名、头像、性别、年龄、生日、星座
  - 联系方式：手机、微信、邮箱、地址
  - 职业信息：公司名称、行业、规模、职位、工龄
  - 社交属性：地区、城市、语言、时区
  - 添加信息：添加时间、添加渠道、添加人

- **互动行为统计**
  - 聊天统计：聊天次数、发消息数、回复率、首次回复时间
  - 活跃统计：日活、周活、月活、平均在线时长
  - 互动趋势：最近30天互动热度图
  - 内容偏好：喜欢的话题类型、回复积极性
  - 情绪分析：客户情绪倾向（积极/中性/消极）

- **客户属性分析**
  - 行业分布：所在行业、企业规模、发展阶段
  - 地域分布：所在省份、城市、区域热力图
  - 来源分析：添加渠道、来源活动、获客方式
  - 状态分析：客户状态、生命周期阶段、风险等级
  - 价值分析：客户价值评分、潜力评估、流失风险

- **购买/转化数据**
  - 交易记录：订单数量、订单金额、订单频次
  - 转化路径：从首次接触到成交的转化路径
  - 复购数据：复购次数、复购金额、复购周期
  - 客单价：平均客单价、消费能力评估
  - 偏好分析：购买偏好、产品偏好、价格敏感度

- **客户评分**
  - 综合评分：基于活跃度、互动、价值的综合得分
  - 活跃度评分：聊天频率、回复及时性、互动深度
  - 价值评分：消费金额、转化潜力、推荐可能性
  - 风险评分：流失风险、投诉风险、合作风险
  - 评分趋势：评分变化趋势、异常波动预警

#### 3.2.5 联系我管理
- **联系我方式配置**
  - 联系方式类型：二维码、电话、企业微信、手机号、邮箱
  - 二维码配置：上传自定义二维码、设置跳转链接
  - 接待规则：单人接待、多人轮询、按部门分配
  - 接待上限：设置每日最大添加人数限制
  - 有效期设置：永久有效、指定日期有效期、使用次数限制

- **联系我列表管理**
  - 列表展示：名称、类型、接待人/部门、状态、创建时间
  - 状态管理：启用、停用、已过期、达到上限
  - 复制功能：快速复制现有联系我配置
  - 删除管理：删除已停用或过期的联系我
  - 批量操作：批量启用/停用、批量删除

- **联系我效果统计**
  - 添加统计：扫码次数、添加成功数、添加失败数
  - 转化统计：转化率、平均转化时间
  - 接待统计：各接待人接待数量、接待效率
  - 趋势分析：日/周/月添加趋势图
  - 对比分析：多个联系我方式效果对比

- **联系我二维码**
  - 二维码生成：自动生成联系我二维码
  - 二维码美化：支持添加Logo、设置颜色、样式
  - 短链生成：生成二维码短链接便于分享
  - 批量下载：批量下载二维码图片
  - 渠道标识：二维码参数标识渠道来源

#### 3.2.6 获客链接管理
- **获客链接生成**
  - 链接类型：短链接、原始链接、二维码
  - 链接来源：自定义域名、系统域名
  - 跳转配置：跳转到企微添加、跳转到联系我、跳转到网页
  - 链接美化：自定义短链接后缀（支持拼音、数字、字母）
  - 批量生成：批量生成多个获客链接

- **链接参数配置**
  - 渠道标识：所属渠道、渠道名称
  - 来源标识：来源活动、来源广告
  - 落地参数：UTM参数（source/medium/campaign/content）
  - 自定义参数：自定义业务参数传递
  - 参数加密：敏感参数加密传输

- **链接有效性管理**
  - 状态管理：启用、停用、已过期
  - 有效期设置：永久有效、指定日期、指定时长
  - 使用次数：设置最大点击次数、达到次数后自动停用
  - 白名单设置：仅指定IP/地区可访问
  - 黑名单设置：屏蔽指定IP/地区访问

- **链接访问统计**
  - 点击统计：总点击量、独立访客数、点击趋势
  - 转化统计：添加人数、转化率、转化漏斗
  - 设备统计：设备类型、操作系统、浏览器
  - 地域统计：访问来源地域分布
  - 时间分析：点击时间段分布、最佳访问时间
  - 来源分析：访问来源网站、搜索关键词

- **链接监控**
  - 实时监控：链接实时点击数据
  - 异常预警：点击量异常波动预警
  - 失效提醒：链接即将过期提醒
  - 黑名单预警：可疑IP访问告警
  - 性能监控：链接跳转速度监控

### 3.3 获客模块

#### 3.3.1 渠道活码
- **活码生成**
  - 活码类型：单人活码、多人活码（员工轮换）、群活码
  - 活码创建：设置活码名称、选择活码类型、上传二维码
  - 批量创建：批量创建多个渠道活码
  - 活码预览：预览活码效果、测试扫码体验
  - 活码模板：常用活码模板快速创建

- **活码参数配置**
  - 渠道信息：渠道名称、渠道描述、渠道归属部门
  - 二维码配置：上传单人二维码、设置群二维码
  - 人员配置：添加接待人员（单人活码）、设置接待组（多人活码）
  - 分组配置：设置接待分组、设置分组优先级
  - 附加信息：设置欢迎语、设置自动打标

- **活码轮换规则**
  - 按比例分配：设置各接待人员接待比例（如：A:40%、B:30%、C:30%）
  - 按时间轮换：按时间段分配接待人员（如：工作时间A，非工作时间B）
  - 顺序分配：按顺序依次分配，循环轮转
  - 智能分配：根据接待人员当前负载智能分配
  - 手动指定：手动指定每次接待人员

- **活码失效处理**
  - 接待上限：设置单人/单群最大添加人数，达到后自动切换
  - 失效设置：设置接待人员失效条件（离职、停用等）
  - 备用机制：失效后自动切换到备用接待人/群
  - 提示设置：失效时显示友好提示文案
  - 通知机制：失效后通知管理员和接待人

- **活码管理**
  - 活码列表：展示所有渠道活码及其状态
  - 状态管理：启用、停用、已失效
  - 编辑功能：修改接待人、调整轮换规则
  - 删除管理：删除已停用活码（需确认）
  - 复制功能：快速复制现有活码配置

- **活码统计**
  - 扫码统计：总扫码次数、独立扫码人数、扫码趋势
  - 添加统计：添加成功数、添加失败数、转化率
  - 接待统计：各接待人接待数量、接待效率
  - 渠道分析：各渠道活码效果对比
  - 异常监控：异常扫码行为监控预警

#### 3.3.2 自动欢迎语
- **欢迎语模板管理**
  - 消息类型：文本消息、图片消息、图文消息、链接消息、小程序消息、视频消息
  - 文本消息：支持文字、emoji、链接
  - 图片消息：上传图片、设置图片尺寸
  - 图文消息：设置标题、描述、封面图、跳转链接
  - 链接消息：设置标题、描述、链接地址、封面图
  - 小程序消息：设置小程序appid、路径、标题、封面图
  - 消息预览：实时预览欢迎语效果

- **欢迎语触发规则**
  - 触发场景：添加后触发、通过后触发、首次聊天触发
  - 标签触发：客户带有指定标签时触发
  - 渠道触发：通过指定渠道活码添加时触发
  - 时间触发：指定时间段添加时触发
  - 条件组合：支持多条件AND/OR组合
  - 优先级设置：多条规则冲突时按优先级匹配

- **欢迎语A/B测试**
  - 测试创建：创建多个版本的欢迎语
  - 流量分配：设置各版本流量占比（如：A:50%、B:50%）
  - 测试周期：设置测试开始时间、结束时间
  - 效果对比：对比各版本的回复率、点击率
  - 自动优胜：测试结束后自动选择优胜版本
  - 手动干预：手动指定正式使用的版本

- **欢迎语效果统计**
  - 发送统计：总发送数、成功发送数、发送失败数
  - 阅读统计：打开率、阅读人数、平均阅读时长
  - 点击统计：链接点击率、小程序打开率、视频观看率
  - 回复统计：回复率、首次回复时间、平均回复时间
  - 转化统计：从添加到转化的转化率
  - 趋势分析：欢迎语效果趋势变化

- **欢迎语高级功能**
  - 个性化欢迎：根据客户信息动态生成欢迎语（如：使用客户昵称）
  - 变量插入：支持插入客户姓名、添加时间、渠道等变量
  - 延迟发送：设置延迟发送时间（如：添加后5分钟发送）
  - 发送频率：设置同一客户重复添加时不重复发送
  - 智能推荐：根据客户标签推荐最佳欢迎语

#### 3.3.3 获客漏斗
- **漏斗数据统计**
  - 曝光量：渠道曝光次数、曝光人数
  - 点击量：点击次数、点击人数、点击率
  - 扫码量：扫码次数、扫码人数、扫码率
  - 添加量：添加成功数、添加失败数、添加率
  - 转化量：转化人数、转化率
  - 漏斗图表：可视化展示各环节数据

- **各环节转化率分析**
  - 曝光→点击：曝光转化率分析
  - 点击→扫码：点击扫码转化率分析
  - 扫码→添加：扫码添加转化率分析
  - 添加→转化：添加转化转化率分析
  - 整体转化：从曝光到转化的整体转化率
  - 漏斗对比：不同渠道/活动的漏斗对比

- **漏斗趋势图表**
  - 日趋势：每日漏斗数据变化趋势
  - 周趋势：每周漏斗数据变化趋势
  - 月趋势：每月漏斗数据变化趋势
  - 环比分析：本周/月与上周/月对比
  - 同比分析：与去年同期对比
  - 预测趋势：基于历史数据预测未来趋势

- **异常数据预警**

  - 对比图表：柱状图、折线图、雷达图可视化对比

  - 改进建议：针对表现较差渠道提供改进建议

- **渠道ROI计算**
  - 成本录入：录入各渠道投入成本（广告费、推广费等）

- **渠道趋势报告**

  - 月报：每月渠道数据总结报告、同比环比分析
  - 自定义报告：自定义报告周期、指标、格式
  - 自动推送：定时自动推送报告到邮箱/企微
  - 报告导出：导出PDF、Excel格式报告

- **渠道质量评估**

  - 转化周期：各渠道客户从添加到转化的平均周期

## 七、非功能性需求

### 7.1 性能要求
- 系统支持至少1000+企业成员并发使用
- 客户列表查询响应时间 < 500ms
- 消息发送支持1000条/分钟

### 7.2 安全要求
- 敏感数据加密存储（企微Secret等）
- 接口访问频率限制
- 操作日志记录（审计追踪）
- 数据备份策略（每日备份）

### 7.3 可用性
- 系统可用性 > 99.5%
- 企微接口调用失败自动重试
- 异常情况监控告警
